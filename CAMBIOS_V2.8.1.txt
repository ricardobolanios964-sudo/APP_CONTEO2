BASE
Esta version parte directamente de V2.8.0.

POR QUE NO SALIA EL AVISO
El aviso necesita la funcion doGet del Code.gs nuevo. Si en Apps Script se pega
el codigo pero NO se publica como "Nueva version" en la MISMA implementacion
(o se crea una implementacion nueva con otra URL), Google sigue usando el script
viejo: los conteos se guardan, pero el aviso nunca aparece.
Comprobacion: abrir la URL /exec en el navegador debe mostrar
{"success":true,"servicio":"APP_CONTEO2","version":"2.8.1"}
Tambien: probar con DOS usuarios distintos (el mismo usuario no se avisa a si mismo).
